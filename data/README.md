# Soru verisi
`src/content.js` içinde uygulamaya dahil edilen **özgün örnek sorular** bulunur. Bunlar ÖSYM'nin çıkmış soruları değildir.

Resmî çıkmış sorular için ÖSYM'nin yayımladığı ve kullanım hakkınız bulunan materyalleri inceleyin. Telif hakkı olan sınav soruları bu projeye izinsiz kopyalanmamıştır.

Kendi lisanslı sorularınızı uygulamadaki **Soru İçe Aktar** ekranından JSON ile yükleyebilirsiniz. Örnek şema: `ornek-sorular.json`.
