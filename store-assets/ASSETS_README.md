# Mağaza görsel paketi

Tasarım: açık/kapalı lacivert arka plan, mor kitap ve hedef/başarı simgesi. Özgün SVG çizimi `branding/app-mark.svg`. ÖSYM logo veya kurumsal marka işareti kullanılmaz.

| Dosya | Ölçü | Amaç |
|---|---|---|
| `google-play/icon-512.png` | 512×512 | Google Play Store simgesi |
| `google-play/feature-graphic-1024x500.png` | 1024×500 | Google Play tanıtım görseli |
| `app-store/icon-1024.png` | 1024×1024 | App Store ikon taslağı |
| `../assets/logo.png` | 1024×1024 | Capacitor native ikon kaynak görseli |
| `../assets/splash.png` | 2732×2732 | Native başlangıç ekranı kaynak görseli |
| `../assets/splash-dark.png` | 2732×2732 | Koyu açılış ekranı taslağı |
| `screenshots/android/*.png` | 1080×1920 | Gerçek React ekranından Chromium mobil Android emülasyon yakalamaları |
| `screenshots/iphone-6.9/*.png` | 1320×2868 | Gerçek React ekranından Chromium iPhone ekran emülasyon yakalamaları |

Üretilmiş PNG dosyaları `GitHub → Actions → Prepare store listing assets → Artifacts` içinde paket halinde tutulur; GitHub deposunda ikili dosya kalabalığı oluşturmamak için otomatik oluşturulur.

**Mağaza gönderiminden önce:** gerçek cihaz/simülatörde aynı ekranları doğrula; yanlış/tekrarlayan içerik, kişisel veri, durumsal hatalar veya eski sınav tarihleri görünmediğini kontrol et. Uygulama içindeki grafikler gerçek kullanıma uygun olmalı. Otomatik ekran görüntüleri tek başına Apple veya Google onayı değildir.
